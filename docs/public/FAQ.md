# ComposeOps FAQ

## ComposeOps 适合谁？
面向个人服务器、自托管用户、Homelab 用户以及希望通过 AI 辅助运维 Docker Compose 服务的人。

## 为什么不直接使用 Dockge？
Dockge 专注于 Compose 管理。ComposeOps 在此基础上增加了 AI Agent、审批门、长期记忆、工作流、备份与运维自动化能力。

## 为什么不直接使用 Portainer？
Portainer 更偏向通用容器管理平台。ComposeOps 更聚焦个人服务器与 Docker Compose 场景，并强调 AI 运维体验。

## AI 会直接执行危险操作吗？
不会。高风险操作需要通过 Approval Gate 明确确认后才会执行。

## 是否支持多节点？
支持 Local、TCP、SSH Docker Host 管理。

## 是否支持离线使用？
基础运维功能可以。AI 能力取决于所配置的模型服务。

## 是否适合作为企业多租户平台？
不适合。ComposeOps 当前定位为单用户运维工作台。
